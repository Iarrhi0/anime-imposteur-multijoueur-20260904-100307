# 🎭 Imposteur Party

Jeux de société d'imposteur, de bluff et de devinettes — solo contre des IA à personnalité, sur un seul téléphone, ou en salon en ligne avec chat vocal. 100 % gratuit.

- 19 jeux, plus de 30 variantes, 20 thèmes (anime, films, séries, jeux vidéo, foot, musique, nourriture…) + packs perso
- IA autonomes : elles déduisent, bluffent, accusent, se défendent, lisent le chat et parlent à voix haute
- Salon en ligne avec code, chat vocal WebRTC de téléphone à téléphone, chat écrit éphémère
- Campagne, défi du jour, badges, mode émission TV, rebondissements surprise

👉 Installation, mise en ligne et configuration : **[GUIDE.md](GUIDE.md)**

```bash
npm install
npm run dev
```
